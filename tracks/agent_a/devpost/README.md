# Devpost submission materials

This directory contains the English-language written materials for the Agent AI-yoh
submission.

- `DEVPOST_PROJECT_DESCRIPTION.md`: paste-ready project description
- `PUBLIC_REPOSITORY.md`: repository link, structure, and public-release checks
- `RUN_AND_ITERATION_LOG.md`: nine-iteration judged-run log
- `RESULTS_AND_RESOURCES.md`: validation results, deltas, resources, and artifacts
- `ARTIFACT_MANIFEST.md`: SHA-256 inventory for the packaged binary and audit files
- `SUBMISSION_CHECKLIST.md`: final upload checklist

Machine-readable audit logs, the locked checkpoint, and the 170,588-row score
file are included in the locally generated `agent_a_devpost_submission.zip`.
Hidden-test metrics are intentionally absent.
